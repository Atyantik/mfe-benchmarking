# Spike — is Module Federation possible with Svelte?

Everything published on this question is a blog post, a broken demo, or a forum thread with no
error message in it. This repo's premise is that a claim without a check is marketing, so the
question gets answered the same way every other one here does: by building it and measuring.

Run: `pnpm --filter @mf-eval/spike-svelte-remote build`

Findings are recorded in `docs/svelte-federation.md`.
